# リサーチ部

インスタ運用に必要な情報源を全て握る部署です。競合アカウント、バズ投稿、トレンドを継続的に調査し、他部署に素材を供給します。

## 入力

- 競合、参考アカウント
- ハッシュタグ
- 発見タブやおすすめ投稿
- 過去投稿実績

## 出力

- 日次レポート（バズ投稿）
- 週次レポート（競合分析）
- トレンドメモ
- クリエイティブ部への引き継ぎ案3つ

## 運用頻度

- 競合アカウント分析: 週2回。同ジャンル5アカウントを選定し、直近1週間で伸びた投稿を「テーマ・構成・ビジュアル・投稿時間」の4軸で分析する。
- バズ投稿の調査: 毎日。ジャンル関連のバズ投稿を5〜10件収集し、保存数・コメント数の多いものを優先する。
- トレンド調査: 週1回。流行中の投稿フォーマット、人気ハッシュタグの変動、ターゲット層が反応しているテーマを整理する。

## 保存先

- `logs/`: 調査ログ、競合分析、トレンドメモ
- `templates/`: 調査レポートの雛形
