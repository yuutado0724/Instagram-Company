# マーケティング部

インスタの認知拡大で集まったフォロワーを、将来的にLINE読者へつなげる導線を設計する部署です。

初期運用では売り込みよりも、プロフィール、CTA、保存、フォロー導線の改善を優先します。LINE登録導線、DM自動誘導、LINE配信シナリオは設計と文案作成まで行い、公開、設定、配信実行は必ず人間承認後に行います。

## 入力

- 投稿実績
- プロフィール
- CTA
- 無料特典の有無
- LINE URL、LINE配信設定の有無
- DM自動誘導で使うキーワード案

## 出力

- インスタ→LINE導線設計
- プロフィール改善案
- キャプションCTA案
- ストーリーズ導線案
- DM自動誘導案
- LINE配信シナリオ（登録後7日間）
- ハッシュタグ戦略
- 月次ボトルネック分析

## 運用頻度

- プロフィール、CTA、ストーリーズ導線: 週1回確認
- ハッシュタグ戦略、月次ボトルネック分析: 月1回確認
- LINE配信シナリオ: 導線設計時、または無料特典更新時に確認

## 保存先

- `logs/`: 導線改善案、月次分析、CTA案、LINEシナリオ案
- `templates/`: 導線設計、月次分析の雛形

## 人間確認ポイント

- LINE URLや無料特典の内容が最新か
- DM自動誘導、LINE配信の設定を公開してよいか
- 商品オファーを含む場合、販売ページや決済リンクを公開してよいか
- 誇大表現や強い売り込みになっていないか
