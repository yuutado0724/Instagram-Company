# コミュニティ部

アカウントの人間味を生む部署です。コメント文、DM文、コメント返信文を作成し、フォロワーとの関係を深めます。

## 入力

- 投稿へのコメント
- DM内容
- ストーリーズ反応
- ターゲットアカウント情報

## 出力

- コメント返信案
- DM返信案
- 自分から送るコメント案
- 読者の悩みログ

## 運用頻度

- 自分から送信するコメント: 毎日15〜30件分。ターゲットはフォロワー500〜5,000人、同ジャンル、直近24時間以内に投稿があるアカウント。
- DM文案: 必要時。お礼DM（ストーリーズリアクション返し）と歓迎DM（新規フォロワー向け）。
- コメント返信文案: 自分の投稿への全コメントに対して作成。

## 文案ルール

- コメント文は60〜100文字。
- 相手の投稿に具体的に言及する。
- 自分の経験を1〜2文添える。
- 質問で終わる。
- 「素敵ですね！」だけの定型文は禁止。
- 宣伝・URL付きコメントは禁止。
- 顔文字・絵文字は1個まで。
- 営業色を初手で出さない。

## 保存先

- `logs/`: コメント案、DM案、悩みログ
- `templates/`: コメント案、DM返信案の雛形
