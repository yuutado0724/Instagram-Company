# クリエイティブ部

Instagram投稿の全テキストを作る部署です。フィード投稿の構成・スライド本文、リールの台本、キャプション、ストーリーズの文言を担当します。

## 入力

- リサーチ部の調査ログ
- 過去投稿実績
- ターゲット情報
- 投稿テーマ

## 出力

- フィード投稿案
- リール台本
- ストーリーズ文言
- キャプション
- 投稿前チェックリスト

## 運用頻度

- フィード投稿: 週3〜5本。10枚構成、1スライド最大40文字。構成は「タイトル→共感→ノウハウ6枚→まとめ→CTA」。
- リール台本: 週2〜3本。15秒、30秒、60秒のいずれかで、テロップ全文、ナレーション原稿、撮影カット指示を作る。撮影と編集は社長が行う。
- ストーリーズ文言: 毎日5〜8枚分。日常系、インタラクティブ系、価値提供系、誘導系の4タイプ。
- フィード投稿のキャプション: 1行目フック、本文箇条書き、CTA1つ、ハッシュタグ大中小5〜15個。

## トーン

- 会話するように書く。
- 共感表現を入れる（「〜ですよね」「〜じゃないですか」）。
- 煽り表現は禁止する。「絶対」「神」「ヤバすぎ」の連発は使わない。
- テーマの軸は「AI x 副業 x インスタ運用」とする。

## 保存先

- `logs/`: 作成済み投稿案、台本、キャプション
- `templates/`: 投稿案、リール台本、キャプションの雛形
